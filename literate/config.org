* 使用说明

本文件是 ~/.config/doom/ 下 Doom Emacs 私人配置的**唯一真源**，用 Org
babel 文学化方式组织：

- 顶层的 ~config.el~ 只是引导文件，启动时把本文件 tangle 成
  ~literate/config.el~ 并加载（只有本文件比 ~.el~ 新时才重新 tangle）。
- 下面的每一个 ~#+begin_src emacs-lisp~ 代码块都是一段真实生效的配置，
  修改后重启 Emacs（或执行 ~M-x org-babel-tangle~ / ~org-babel-load-file~）生效。
- 普通文字段落只作说明，不会被加载。

迁移自原 ~config.el~（备份见 ~config.el.bak-20260902~），要点：

- 原代码开头指向不存在的 ~/.doom.d/lisp~ 的死路径已修正为真实的
  ~doom-user-dir/lisp~（即 ~/.config/doom/lisp~）；
- 原模板注释里被注释掉的示例（全屏、字体等）已移入对应章节的说明文字，
  不再出现在生成的 ~.el~ 里；
- 末尾 ~(load! "lisp/dsh")~ 因生成文件位于 ~literate/~ 子目录、相对基准
  变化，改为显式传入目录。

** macOS 菜单栏番茄钟联动

给 [[https://github.com][macOS 菜单栏番茄钟]]（原生 SwiftUI app）提供的桥接函数，通过
~emacsclient --eval~ 调用。每个函数返回一个 JSON 字符串（用 ~json-encode~），
方便 Swift 那边直接解析，不用去啃 elisp 的 prin1 转义。

- ~my/pomodoro-bridge-list-todos~ —— 列出 org-agenda-files 里所有未完成的
  TODO，带 file/pos/heading/path，供 Mac app 弹窗选择。
- ~my/pomodoro-bridge-clock-start~ —— 按 Mac app 传回的 file/pos/heading
  在对应标题下 clock-in 并开始一个 org-pomodoro。
- ~my/pomodoro-bridge-status~ —— 查询当前 org-pomodoro 状态/剩余秒数/正在
  clock 的标题，Mac app 用来同步菜单栏倒计时显示。
- ~my/pomodoro-bridge-stop~ —— 终止当前番茄并 clock-out（对应 Mac app 的
  "暂停"按钮，因为 org-pomodoro 本身没有真正的暂停）。
- ~my/pomodoro-bridge-stats~ —— 按标题统计今天/近 7 天的 clock 时长，
  给 Mac app 的统计面板用，直接复用 org-clock-sum，不在 Swift 里重新解析
  LOGBOOK。

#+begin_src emacs-lisp
(after! org
  (require 'json)
  (require 'org-pomodoro)

  (defun my/pomodoro-bridge--todo-p ()
    (let ((state (org-get-todo-state)))
      (and state (member state org-not-done-keywords))))

  (defun my/pomodoro-bridge-list-todos ()
    "JSON 数组：org-agenda-files 里所有未完成 TODO 的 file/pos/heading/path。"
    (let (entries)
      (dolist (file (org-agenda-files))
        (when (file-exists-p file)
          (with-current-buffer (find-file-noselect file)
            (org-with-wide-buffer
             (org-map-entries
              (lambda ()
                (when (my/pomodoro-bridge--todo-p)
                  (push (list (cons "file" file)
                              (cons "pos" (point))
                              (cons "heading" (org-get-heading t t t t))
                              (cons "path" (mapconcat #'identity
                                                       (org-get-outline-path)
                                                       " > ")))
                        entries)))
              nil 'file)))))
      (json-encode (nreverse entries))))

  (defun my/pomodoro-bridge-clock-start (file pos heading)
    "在 FILE:POS（校验标题文本等于 HEADING）处 clock-in 并开始 org-pomodoro。"
    (condition-case err
        (progn
          (with-current-buffer (find-file-noselect file)
            (widen)
            (goto-char (min (max pos (point-min)) (point-max)))
            (beginning-of-line)
            (unless (and (looking-at org-complex-heading-regexp)
                         (equal (org-get-heading t t t t) heading))
              (goto-char (point-min))
              (unless (re-search-forward
                       (concat "^\\*+[ \t]+.*" (regexp-quote heading)) nil t)
                (error "找不到标题：%s" heading))
              (beginning-of-line))
            (when (org-clocking-p) (org-clock-out))
            (org-clock-in)
            (save-buffer)
            (org-pomodoro-start :pomodoro))
          (json-encode (list (cons "ok" t))))
      (error (json-encode (list (cons "ok" :json-false)
                                 (cons "error" (error-message-string err)))))))

  (defun my/pomodoro-bridge-status ()
    "当前 org-pomodoro 状态，JSON：{state, remaining, heading, count}。"
    (json-encode
     (list (cons "state" (symbol-name (or org-pomodoro-state :none)))
           (cons "remaining" (if (org-pomodoro-active-p)
                                  (round (org-pomodoro-remaining-seconds))
                                0))
           (cons "heading" (if (org-clocking-p)
                                (substring-no-properties org-clock-heading)
                              ""))
           (cons "count" org-pomodoro-count))))

  (defun my/pomodoro-bridge-stop ()
    "终止当前番茄并 clock-out（已计时部分会保留，见 org-pomodoro-keep-killed-pomodoro-time）。"
    (condition-case err
        (let ((buf (and (org-clocking-p) (marker-buffer org-clock-marker))))
          (when (org-pomodoro-active-p) (org-pomodoro-kill))
          (when (org-clocking-p) (org-clock-out))
          (when buf (with-current-buffer buf (save-buffer)))
          (json-encode (list (cons "ok" t))))
      (error (json-encode (list (cons "ok" :json-false)
                                 (cons "error" (error-message-string err)))))))

  (defun my/pomodoro-bridge-stats ()
    "按标题统计今天/近 7 天的 clock 分钟数，JSON 数组。"
    (let* ((today-start (apply #'encode-time 0 0 0 (nthcdr 3 (decode-time))))
           (week-start (time-subtract today-start (* 6 86400)))
           (now (current-time))
           results)
      (dolist (file (org-agenda-files))
        (when (file-exists-p file)
          (with-current-buffer (find-file-noselect file)
            (org-with-wide-buffer
             (org-clock-sum today-start now nil :clock-today)
             (org-clock-sum week-start now nil :clock-week)
             (org-map-entries
              (lambda ()
                (when (my/pomodoro-bridge--todo-p)
                  (push (list (cons "heading" (org-get-heading t t t t))
                              (cons "path" (mapconcat #'identity
                                                       (org-get-outline-path)
                                                       " > "))
                              (cons "todayMinutes"
                                    (or (get-text-property (point) :clock-today) 0))
                              (cons "weekMinutes"
                                    (or (get-text-property (point) :clock-week) 0)))
                        results)))
              nil 'file)))))
      (json-encode (nreverse results)))))
#+end_src

* Org：字体与 faces（Ricing Org Mode）

Tufte 风格：正文用旧式衬线（教程用 ET Book / ~EtBembo~，未安装则自动回退
Iowan Old Style），标题用近黑墨色、以字号与斜体区分层级；代码、表格用等宽
字。正文衬线由 ~variable-pitch-mode~ 生效（见 hook 一节）。字高为相对默认
字体（本配置 14pt）的倍数，可自行调整。

#+begin_src emacs-lisp
(require 'cl-lib)

;; 字体选择：优先教程字体，未安装则回退 macOS 自带字体
(defun my/first-available-font (candidates fallback)
  "Return the first installed font family in CANDIDATES, else FALLBACK."
  (or (cl-loop for family in candidates
               if (member family (font-family-list))
               return family)
      fallback))

(defconst my/org-serif-font
  (my/first-available-font '("ETBookOT" "EtBembo" "Iowan Old Style" "Charter" "Georgia")
                           "Georgia"))

(defconst my/org-mono-font
  (my/first-available-font '("Source Code Pro" "Menlo")
                           "Menlo"))

(defconst my/org-serif-mono-font
  (my/first-available-font '("Verily Serif Mono")
                           my/org-mono-font))
#+end_src

#+begin_src emacs-lisp
(defun my/apply-org-rices ()
  "Apply Tufte-style Org faces (lepisma's Ricing up Org Mode)."
  (when (featurep 'org)
    (require 'org-faces)
    (require 'org-indent)
    (let ((ink "#1c1e1f")    ; 墨色：标题与正文
          (muted "#8a8a8a")  ; 弱化：日期、特殊行、block 首尾
          (code "#525254"))  ; 代码前景
    ;; 基础字体
    (set-face-attribute 'variable-pitch nil
                        :family my/org-serif-font :height 1.3 :foreground ink)
    (set-face-attribute 'fixed-pitch nil
                        :family my/org-mono-font :height 1.0)
    ;; 文档标题与信息
    (set-face-attribute 'org-document-title nil
                        :inherit nil :family my/org-serif-font
                        :height 1.8 :weight 'normal :foreground muted
                        :underline nil)
    (set-face-attribute 'org-document-info nil
                        :family my/org-serif-font :height 1.2 :slant 'italic)
    ;; 标题：墨色 + 层级缩放/斜体（不用彩色）
    (set-face-attribute 'org-level-1 nil :inherit nil :family my/org-serif-font
                        :height 1.6 :foreground ink)
    (set-face-attribute 'org-level-2 nil :inherit nil :family my/org-serif-font
                        :height 1.4 :slant 'italic :foreground ink)
    (set-face-attribute 'org-level-3 nil :inherit nil :family my/org-serif-font
                        :height 1.25 :slant 'italic :foreground ink)
    (set-face-attribute 'org-level-4 nil :inherit nil :family my/org-serif-font
                        :height 1.1 :slant 'italic :foreground ink)
    (set-face-attribute 'org-level-5 nil :inherit nil :family my/org-serif-font
                        :height 1.0 :weight 'bold :foreground ink)
    (set-face-attribute 'org-level-6 nil :inherit nil :family my/org-serif-font
                        :height 1.0 :weight 'bold :foreground ink)
    (set-face-attribute 'org-level-7 nil :inherit nil :family my/org-serif-font

    ;; 完成标题加删除线
    (set-face-attribute 'org-headline-done nil :strike-through t)
    ;; 链接与弱化文字
    (set-face-attribute 'org-link nil :underline nil :foreground "#458588")
    (set-face-attribute 'org-special-keyword nil :height 0.9 :foreground muted)
    (set-face-attribute 'org-meta-line nil :height 0.9 :foreground muted)

                        :foreground code :height 0.9)
    (set-face-attribute 'org-verbatim nil :family my/org-serif-mono-font
                        :foreground code :height 0.9)
    (set-face-attribute 'org-block nil :family my/org-mono-font)
    (set-face-attribute 'org-block-begin-line nil :family my/org-mono-font

* dsh（DeepSeek Harness）集成

快捷键：~C-c d ?~ / ~SPC d ?~ 提问，~SPC h r r~ 重启生效。因为本文件生成的
~literate/config.el~ 位于子目录，相对路径基准不再是 ~$DOOMDIR~，故显式传入

* cch（Claude Code Headless）集成

跟上面的 dsh 是同一个套路，只是换成 ~claude -p~（Claude Code 的单次问答
"print" 模式），不是交互式 ~claude-code.el~ 会话，问一句、答一句，答案进
~*cch*~ buffer，不会碰你的文件。

快捷键：
- ~C-c q a~ — 异步提问，答案进 ~*cch*~
- ~C-c q r~ — 用选中区域当问题
- ~C-c q i~ — 同步提问，直接把答案插到光标处
- ~C-c q I~ — 选中区域当问题，答案插在区域后面
